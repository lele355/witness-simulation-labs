# Witness 仿真实验

制造系统建模与仿真课程实验：基本练习与流水线优化

## 实验内容

### 实验一 · Witness 基本练习

熟悉 Witness 建模环境，建立基础模型并采集六类统计量：

Buffer（缓冲区）· Conveyor（传送带）· Labor（劳动力）· Machine（机器）· Part（零件）· Variable（变量）

### 实验三 · 流水线建模与仿真

建立流水线模型，对比**改善前 / 改善后**两种方案，从 Conveyor、Labor、Machine、Part 四类统计量分析改善效果。
